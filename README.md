## 🚀 **Overview**
**ChatApp** is a basic, real-time chat application where users can join different chat rooms and communicate instantly. It’s designed to provide an easy and fluid chatting experience, whether it's for casual conversations or focused group discussions. Powered by **Socket.io**, it enables lightning-fast communication between users in various chat rooms.

---

## ✨ **Features**

### 💬 **Real-time Communication**
- Instant messaging between users in different chat rooms.
- Multiple chat rooms for users to join and communicate with others.

### 🏷️ **User-friendly Interface**
- Simple, clean design for easy navigation and chatting.
- Join chat rooms with a single click.

### 👥 **Multiple Chat Rooms**
- Create and join multiple rooms to chat with different groups of people.
- Engage with multiple conversations at once.

### 📡 **Powered by Socket.io**
- Fast, reliable messaging powered by **Socket.io**.
- Real-time updates to keep conversations flowing smoothly.

## 🖥️ **Installation**

To set up **ChatApp** on your local machine, follow these steps:

1. **Clone the Repository**  
   ```bash
   git clone https://github.com/your-repository-link.git
2.  **Install Dependencies**  
   ```bash
   npm install
```
3.  **Start the Development Server**  
   ```bash
   npm start
```
4. **Access the Application :**
   Navigate to http://localhost:3000 in your browser.
